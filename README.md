# Sahara Star Tours - Site Web Statique

Site web officiel pour **Sahara Star Tours**, agence de voyage privée au Maroc et dans le désert du Sahara.

## Structure du projet (Clean & Simple)
```text
saharastartours/
├── index.html        # Page principale (HTML5 + Tailwind CDN + Alpine.js)
├── assets/           # Images, photos des circuits et logo
└── README.md         # Documentation
```

## Technologies utilisées
- **HTML5** moderne & sémantique
- **Tailwind CSS** (via CDN avec palette et styles sur-mesure)
- **Alpine.js** (via CDN pour la réactivité, calculateurs, onglets et menus)
- **Font Awesome 6** & **Google Fonts** (Playfair Display, Outfit)

## Utilisation
Il suffit d'ouvrir le fichier `index.html` directement dans n'importe quel navigateur, ou de le glisser/déposer sur un hébergeur comme Netlify, Vercel, Hostinger, cPanel, GitHub Pages, etc.
